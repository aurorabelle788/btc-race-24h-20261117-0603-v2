Dip-buying bot for the cbBTC/USDC 24h race. Buys 1.10% dips off the 60-bar rolling high, exits at +2.00% take-profit, -1.50% stop-loss, or after 480 bars held; 99% of cash per trade, 20% drawdown halt. Dev window: net PnL +$25.32 (5 trades, 3 wins, max drawdown 1.30%).

## Run it

```sh
python3 -P -s main.py
```
